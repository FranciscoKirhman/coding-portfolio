# Application tracker

Public copy of the tracker, with no personal data. Open `index.html` and use **Añadir puesto** to record applications. The data is saved in that browser (`localStorage`); **Guardar** downloads a copy of the HTML with your data inside, and Herramientas can export or import JSON.

This copy is generated by `scripts/build_public_tools.py`, which empties every data block, removes the private integrations (relay, mobile sync, local assistant) and fails if any company name, path or secret from the source data remains.
