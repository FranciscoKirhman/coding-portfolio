# Application tracker

Public copy of the tracker. It opens with **fictional demo data**: every company marked "(demo)" is invented. **Borrar datos de demo** removes them. Use **Añadir puesto** to record applications. The data is saved in that browser (`localStorage`); **Guardar** downloads a copy of the HTML with your data inside, and Herramientas can export or import JSON.

This copy is generated by `scripts/build_public_tools.py`, which empties every data block, removes the private integrations (relay, mobile sync, local assistant) and fails if any company name, path or secret from the source data remains.
