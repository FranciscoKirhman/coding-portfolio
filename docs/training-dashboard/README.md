# Training dashboard

Public copy of the dashboard, with no personal data. Open `index.html`, press **Cargar profiles.json** and pick your file. The data is saved only in that browser (`localStorage`); **Quitar mis datos** deletes it.

## Formato

`profiles.json` is an object with one key per person. Each profile follows this shape; any list can start empty.

```json
{
  "ana": {
    "displayName": "Ana",
    "bodyType": "female",
    "hasData": true,
    "chips": [{ "k": "Nivel", "v": "Intermedio" }],
    "cycle": { "badge": "Semana 1 de 4", "detail": "", "meso": { "semana": 1, "total": 4, "deload": 4, "inicio": "2026-09-01", "nota": "" } },
    "weekNote": "Texto con **markdown** simple",
    "weekTodo": "",
    "fuente": "mi_registro.md",
    "WEEKDAYS": [
      {
        "day": "Lun", "date": "2026-09-14", "focus": "Tren inferior", "tag": "", "rationale": "",
        "cardio": "", 
        "warmup":  [{ "name": "Movilidad de cadera", "how": "2 × 10 por lado" }],
        "stretch": [{ "name": "Isquiotibiales", "how": "30 s por lado" }],
        "exercises": [{ "name": "Sentadilla", "sets": [{ "carga": "60 kg", "reps": "8", "rir": "2", "descanso": "2 min" }] }]
      }
    ],
    "MUSCLES": [
      { "name": "Cuádriceps", "recent": 10, "hist": 9, "lo": 10, "hi": 20, "tier": "good", "trend": "", "note": "", "ex": [] }
    ],
    "CHARTS": [
      { "name": "Sentadilla", "data": [], "pattern": "insuficientes_datos", "lo": 0, "hi": 0, "change": "", "rationale": "" }
    ],
    "SESSIONS_FULL": [
      { "date": "2026-09-10", "dlabel": "Jue 10 sep", "title": "Pierna", "hora": "19:00", "dur": "60 min", "vol": "", "com": "", "rec": "",
        "exercises": [{ "ej": "Sentadilla", "carga": "60", "reps": "8" }] }
    ]
  }
}
```

`tier` accepts `critical`, `warning` or `good`. `pattern` accepts `ascendente_claro`, `meseta_oscilante`, `volatil_sin_tendencia` or `insuficientes_datos`. Without `bodyType` the anatomical map uses the male figure.

The anatomical diagram comes from [MuscleMap](https://github.com/melihcolpan/MuscleMap) by Melih Colpan, MIT license. This copy is generated by `scripts/build_public_tools.py`.
